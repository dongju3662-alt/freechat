📌 개발자 전달 노트 — 목업 09 · 에이전시 코드 입력

FREECHAT · 여자회원 전용 기능 · 목업 이미지와 함께 전달
1
노출 조건
유저 프로필의 gender = "female" 일 때만 에이전시 코드 관련 화면 및 설정 메뉴 노출.
gender = "male" 인 경우 설정 탭에서 에이전시 코드 메뉴 항목 자체가 존재하지 않음. 라우팅 접근도 차단.
2
진입 경로 2가지
경로 A 온보딩 자동 이동 카카오 로그인 → 프로필 설정 → 에이전시 코드 입력 (3단계)
경로 B 설정에서 재진입 설정 → 에이전시 코드 → 미등록이면 입력 화면 / 등록됐으면 확인 화면
3
코드 유효성 검사 (API)
[확인] 버튼 탭 시 서버 API 호출 → 존재하는 에이전시 코드인지 확인.
· 성공 → 등록 완료 화면 (Screen 3) 으로 전환
· 실패 → 입력 필드 빨간 테두리 + 오류 메시지 표시 (Screen 2)
4
코드 없이 시작하기
"코드 없이 시작하기" 선택 시 → 홈(메인) 화면으로 이동.
이후 설정 탭 → 에이전시 코드 메뉴에서 언제든 재입력 가능.
코드 미등록 상태에서는 적립금이 쌓이지 않음 (백엔드 적립 로직 비활성).
5
코드 변경 규칙
여자회원 본인은 코드를 직접 변경할 수 없음.
슈퍼관리자 만 메인 어드민에서 코드 변경 가능.
코드 변경 시 기존 적립금은 새 에이전시로 그대로 이관됨 (소멸 없음).
6
적립 시작 시점
코드 등록 완료 시점부터 채팅 라인 적립 시작.
등록 이전에 주고받은 채팅은 소급 적용 없음.
적립 기준: 채팅 1라인 = 10원 (5글자 미만 라인은 적립 제외).
7
성별에 따른 설정 메뉴 차이
남자 설정 메뉴 프로필 수정 / 알림 설정 / 차단 목록 / 공지사항 / 문의하기 / 약관 / 회원 탈퇴
여자 설정 메뉴 위 항목 전체 + 에이전시 코드 항목 추가
