FLOW NOTES
08A 에이전시 여자회원 채팅 리스트
· 최상단: 원형 계정 전환 탭 (최대 3개)
· 활성 계정: 보라 테두리 + 이름 표시
· 비활성 계정: 흐린 테두리, 이름 미표시
· 탭 클릭 시 해당 계정 채팅 리스트로 즉시 전환
· 닉네임 옆 ♥ 맞팔 / ♡ 단방향 즐겨찾기
· "매칭 중..." 특수 상태 표시
08B 일반회원 채팅 리스트
· 단일 계정 → 계정 전환 탭 영역 완전 미노출
· 헤더 바로 아래 채팅 리스트만 표시
· 닉네임 옆 ♥ 맞팔 / ♡ 단방향 즐겨찾기
· "매칭 중..." 특수 상태 표시
· 안읽음 뱃지 / 온라인 초록 점 표시
09 채팅방
· 헤더: 뒤로가기 | 아바타+닉네임 | 신고/차단
· 신고·차단 동일 회색 스타일 (법적 필수)
· 내 말풍선: 우측 보라색 / 상대: 좌측 어두운색
· + 버튼: 매칭 직후 즉시 활성화
10 플러스 메뉴
· + 클릭 → X로 변경 + 하단 패널 슬라이드업
· 메뉴: 사진 / 카메라 / 이모티콘 (3종)
· 파일 전송 없음
· 뒤 채팅 영역 딤 처리
